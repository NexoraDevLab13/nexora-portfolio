# 🚀 NEXORA

### Plataforma web de gestión contable, financiera y administrativa

NEXORA es un **prototipo funcional de software empresarial** desarrollado para demostrar la aplicación de tecnologías de desarrollo web en procesos contables, financieros y administrativos.

El proyecto combina conocimientos de **contabilidad y desarrollo de software**, con una arquitectura orientada a la gestión de información empresarial.

---

## 🧩 Funcionalidades

- 🏢 Gestión de empresa
- 👥 Gestión de usuarios y accesos
- 📚 Catálogo de cuentas contables
- 🧾 Registro y gestión de pólizas
- 💰 Control de bancos y movimientos
- 💵 Gestión de monedas y tipos de cambio
- 📊 Reportes e información financiera
- 🧮 Procesos fiscales y administrativos
- 📦 Control administrativo e inventarios
- 🔐 Validaciones y control de acceso
- 📝 Registro y trazabilidad de operaciones

## 🏗️ Arquitectura

El sistema está desarrollado bajo una arquitectura web con separación entre:

**Frontend → API REST → Backend → Base de datos**

Esto permite organizar la lógica de negocio, el acceso a datos y la interfaz de usuario de manera independiente.
